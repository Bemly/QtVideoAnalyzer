# H.263 示例视频集（一页）

> 存放：`tools/samples/`（已 gitignore，不入库；本页只留清单 + 复现命令）。
> 本机实测：`ffmpeg 9.0.2`（`/opt/homebrew/bin/ffmpeg`）。
> 前提：H.263 Baseline 只接受固定尺寸 128x96 / 176x144 / 352x288 / 704x576 /
> 1408x1152（其他尺寸 `h263` 编码器直接报错，见 §3 证据）。

## 1. 清单（ffprobe 实测）

| 文件 | 来源 | 视频实测 | 音频实测 | 时长 / 大小 |
|---|---|---|---|---|
| `test_h263_qcif_cbr.mov` | 本地生成（§2 命令 1） | h263 (`Lavc h263`)，176x144 QCIF，yuv420p，30fps，120 帧，流码率 ~154k | aac mono 64k | 4.0s / 112 KiB |
| `test_h263_cif_vbr.mov` | 本地生成（§2 命令 2） | h263 (`Lavc h263`)，352x288 CIF，yuv420p，30fps，120 帧，流码率 ~1888k（`-q:v 3` VBR） | aac mono 64k | 4.0s / 959 KiB |
| `test_h263plus_annex.mov` | 本地生成（§2 命令 3） | h263 (`Lavc h263p` + Annex D/F `-umv -aiv`)，352x288 CIF，yuv420p，30fps，120 帧，流码率 ~1006k | aac mono 64k | 4.0s / 527 KiB |
| `real_3g_sonyk750i.3gp` | 真实 3G 手机实拍（§2 URL） | h263，176x144 QCIF，yuv420p，~9.5fps，114 帧，流码率 ~66k | amr_nb mono 8kHz 12.8k | 12.2s / 117 KiB |

全部 < 5MB；本地 3 个 ~4s（3–5s 要求内）；真实片 12.2s（原样保留，未剪）。

## 2. 来源 / 生成命令

真实片 URL：<https://samples.ffmpeg.org/mobileVideo_3gp/MOV00001_sonyk750i.3gp>
（ffmpeg 官方 sample 站 `mobileVideo_3gp/` 目录，Sony Ericsson K750i 实拍 3GP，
H.263 视频 + AMR-NB 音频，典型 3G-324M/彩信时代组合；下载后改名为
`real_3g_sonyk750i.3gp`，内容未改动）。

本地生成（仓库根目录执行；运动 `testsrc2` + 每 2.5s 红闪 1 帧充当场景切换，
与 `tools/make_test_videos.sh` 同源）：

```bash
# 1. QCIF CBR 128k（Baseline h263 编码器）
ffmpeg -hide_banner -y -f lavfi -i \
"testsrc2=size=176x144:rate=30:duration=4,drawbox=c=red:t=fill:enable='lt(mod(t+1.25,2.5),0.034)':x=0:y=0:w=iw:h=ih,format=yuv420p" \
-f lavfi -i "sine=frequency=440:duration=4:sample_rate=44100" \
-t 4 -r 30 -c:v h263 -pix_fmt yuv420p -g 30 \
-b:v 128k -minrate 128k -maxrate 128k -bufsize 256k \
-c:a aac -b:a 64k -ac 1 tools/samples/test_h263_qcif_cbr.mov

# 2. CIF VBR（Baseline h263 编码器，-q:v 3 真 VBR，无 min/max 钳制）
ffmpeg -hide_banner -y -f lavfi -i \
"testsrc2=size=352x288:rate=30:duration=4,drawbox=c=red:t=fill:enable='lt(mod(t+1.25,2.5),0.034)':x=0:y=0:w=iw:h=ih,format=yuv420p" \
-f lavfi -i "sine=frequency=660:duration=4:sample_rate=44100" \
-t 4 -r 30 -c:v h263 -pix_fmt yuv420p -g 30 -q:v 3 \
-c:a aac -b:a 64k -ac 1 tools/samples/test_h263_cif_vbr.mov

# 3. H.263+ Annex（h263p 编码器，D=UMV + F/AIC 相关 -aiv；CIF）
ffmpeg -hide_banner -y -f lavfi -i \
"testsrc2=size=352x288:rate=30:duration=4,drawbox=c=red:t=fill:enable='lt(mod(t+1.25,2.5),0.034)':x=0:y=0:w=iw:h=ih,format=yuv420p" \
-f lavfi -i "sine=frequency=880:duration=4:sample_rate=44100" \
-t 4 -r 30 -c:v h263p -pix_fmt yuv420p -g 30 -b:v 768k -umv 1 -aiv 1 \
-c:a aac -b:a 64k -ac 1 tools/samples/test_h263plus_annex.mov
```
